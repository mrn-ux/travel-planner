# Faro — Web App UI Kit

Click-through recreation of the Faro conversational flow: Home (intake) → Trip Planner (chat + recommendations) → Hotels (comparison table + booking) → Itinerary (day cards + budget) → My Trips.

Built from `uploads/DESIGN-SYSTEM.md` only — no Figma or codebase source was attached, so screen composition follows the spec's component definitions and layout rules (§4) rather than a real captured screen. Treat this as a faithful assembly of the spec's own components, not a pixel-exact recreation of a shipped product.
