# Current UI (as implemented, 2026-10-13)

The mockups in this folder (`Faro Screens.dc.html`, `Mobile Screens.dc.html` and the components) are the layout source of truth and are **not** regenerated; the implementation adds the visual layer described in `docs/UI-SPEC.md` section 4. This page records how each screen looks now. Screenshots (also in `docs/screenshots/faro-screens.zip`):

| Screen | Image | What it shows |
|---|---|---|
| Login | `01-login.jpg` | Ha Long Bay photo, welcome text and four highlighted bars on the left, sign-in card on the right, theme dots top right |
| Plan a trip | `02-plan-a-trip.jpg` | Photo banner "Welcome to Faro"; Trip details card (country and city dropdowns, dates, travelers, budget, preferences, New trip) beside the chat panel |
| Search: Hotels | `03-search-hotels.jpg` | Solid panel, lodging banner, summary pills, tabs, step line, filters (dates, guests, rooms, rating), results table |
| Search: Transport | `04-search-transport.jpg` | Vehicle banner, start country and city, date, mode chips, flights with Book this flight |
| Search: Places | `05-search-places.jpg` | Top 10 places with tick-boxes, Add to trip, photo, hours and fee |
| Hotel details | `06-hotel-details.jpg` | Lodging banner, gallery, details, rooms column |
| Trip plan | `07-trip-plan.jpg` | Country banner, day-by-day itinerary beside the budget breakdown, Download |
| My trips | `08-my-trips.jpg` | "Your adventures" banner and a card per trip |

The booking screen shows the same lodging banner above the step indicator; it needs a booking in progress and is not in the set.
