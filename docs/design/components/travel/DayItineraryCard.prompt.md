One itinerary day, segmented into Morning/Afternoon/Evening sub-sections.

```jsx
<DayItineraryCard day={1} date="12 Nov 2026" morning={[
  { title: 'Belém Tower', duration: '1h 30m', cost: 'USD 6.00', hours: 'Open 10:00–17:30', travelTime: '15m' },
]} />
```

Each item shows title, tabular duration + cost, an optional opening-hours note, and an optional travel-time connector to the next stop.
