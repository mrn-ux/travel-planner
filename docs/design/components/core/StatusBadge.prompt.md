Certainty label that must sit beside every time-sensitive figure in the product — never color alone.

```jsx
<StatusBadge status="confirmed" />
<StatusBadge status="estimated" />
<StatusBadge status="unavailable" />
```

Confirmed = green + check. Estimated = amber + tilde. Unavailable = neutral grey + dash. Used in hotel/transport comparison rows, itinerary cost lines, and the budget breakdown.
