Faro screens · current implementation (web, 1280px)

Redrawn from the running application on 2026-10-13. It replaces nothing in Faro Screens.dc.html (the original layout source of truth, kept for history): it shows the same seven routes and the search tabs with the visual layer added (photo banners, faint page photo, solid content panel, themes, the login welcome panel). Photos are drawn as gradients; in the app they are Wikipedia lead images matched to the page (the country, lodging pictures on hotel pages, vehicles on transport pages). Money is shown as a currency code with tabular figures; every time-sensitive figure carries a Confirmed, Estimated or Unavailable label.
